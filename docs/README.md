# Documentation

This directory holds live design and maintenance docs for poc-10.

- `RULES.md`: architecture, ownership, projector, handler, wire, and guardrail
  rules.
- `documentation_guide.md`: documentation style for core and protocol modules.
- `auth.md`: auth authority, key-material, rotation, purge, and key-healing
  invariants.
- `negentropy_recs.md`: dep-aware sync and negentropy recommendations.

`archived/` contains planning notes and proposals that are no longer the source
of truth. Keep archived docs for historical context only; update live docs and
tests when current behavior changes.
